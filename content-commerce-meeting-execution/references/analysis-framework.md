# 分析框架

## 1. 待办原子化

一条合格待办尽量包含：

```text
动作 + 对象 + 交付物 + 数量/范围 + 验收标准 + 截止时间 + 验收证据
```

示例只用于展示颗粒度，不代表通用阈值：

```text
把“优化封面”拆成“产出 3 版封面，按同一投放条件完成测试，并把每版展现、点击和成本截图发到指定文档”。
```

遇到下面的词时继续追问或拆解：优化、提升、加强、跟进、关注、推进、持续做、尽快、差不多、基本完成。

## 2. 优先级

| 级别 | 判断标准 | 时间要求 |
|---|---|---|
| P0 | 不做则当前项目的增长逻辑、关键验证或交付链路不成立 | 本周必须完成 |
| P1 | 重要但不阻断核心验证 | 本周启动，通常两周内完成 |
| P2 | 锦上添花，推后不会改变当前关键判断 | 有余力再做 |

不要按“老板提了几次”或“讨论时间长”自动判为 P0。优先检查：

1. 是否阻断后续多个事项；
2. 是否存在不可逆的时间窗口；
3. 是否直接验证当前最关键假设；
4. 不做的损失是否高于其他事项。

不要把所有保障条件都升级为 P0：

- 预算上限、价格不变、禁止新增渠道等写成实验边界；
- 通过线、止损线写成执行和复盘规则；
- 为了补足证据新增的测量或留痕动作，优先并入相关 P0 的启动前置条件；
- 只有存在独立交付物、独立执行动作或会议明确承诺时，才新增一条待办。

## 3. 交付标准

交付标准必须能二元判断：

- 文档类：链接已提交到约定位置，并由指定验收角色确认；
- 测试类：规定样本、条件和周期已完成，原始数据可查看；
- 内容类：规定数量的成品已产出并进入指定审核或投放环节；
- 决策类：备选项、判断依据、负责人签字或群内确认齐全。

如果标准由负责人定义，写成：

```text
[待确认] 负责人须在启动前把基线、目标、样本量和止损值同步到约定位置；未同步即不视为启动。
```

## 4. 三类关键变量

每个 P0/P1 至少检查三类变量，并写“触发条件 → 动作”：

| 变量 | 常见内容 | 合格写法 |
|---|---|---|
| 外部变量 | 平台规则、竞品动作、达人状况、库存、季节性 | 出现何种变化后暂停、换方案或升级决策 |
| 数据变量 | 实际结果偏离基线、目标或最低样本量 | 连续多少天或达到多少样本仍不达标时，改什么或停什么 |
| 人员变量 | 请假、离职、跨项目冲突、产能不足 | 备用角色、交接材料和最迟切换时间 |

没有输入数字时不要编阈值。先指定需要补的基线、观察窗和决策人。

## 5. 常见会议盲区

这张清单用于对照，不代表目标品牌已经存在这些问题。只选择与会议和当前阶段相关的 3–5 项，并写成可验证假设。

| 盲区类型 | 典型信号 | 为什么容易被跳过 |
|---|---|---|
| 付费流与自然流此消彼长 | 投放消耗上升，自然阅读下降 | 团队只看付费结果，可能忽略过度投流对自然分发的影响 |
| 达人依赖 | 达人内容效果显著高于素人或品牌号 | 达人有接单、疲劳和停更周期，单点依赖会中断内容供应 |
| 退货率异常 | 支付增长的同时退款也增长 | 投流与自然流可能带来不同人群，只看成交会掩盖真实质量 |
| 搜索页与发现页失衡 | 只经营一个流量入口 | 一个负责泛触达，一个承载精准意图，结构失衡会限制增长 |
| 内容模板边际收益递减 | 同一模板连续使用后点击率走低 | 平台同质化约束和用户审美疲劳常被“过去有效”掩盖 |
| 竞品复制有效模板 | 搜索结果出现高度相似内容 | 原有表达优势被行业复制，需要判断加速放大还是更换公式 |
| 断货或季节性 | 会议只讨论内容和预算，没有讨论供给 | 内容跑通后缺货会浪费测试和投放成果 |
| 团队产能上限 | P0 数量明显高于可用人力 | 排出优先级不等于事项可以并行完成 |

每个盲区的验证动作需包含：建议角色、完成时间、投入上限、要读取的数据或样本、交付位置。

如果会议没有提供完成时间、投入上限、数据范围或样本量，分别写“待确认”或使用依赖节点，不要自行补具体日期和数字。

## 6. 单一胜负手

胜负手不是“最重要的日常工作”，而是结果会改变后续多项决策基准的单一验证事项。

候选事项按以下顺序判断：

1. **决策杠杆**：结果会让哪些事项加速、停止或改方向；
2. **阶段匹配**：是否解决当前阶段最关键的不确定性；
3. **证据差距**：能否在两周内得到足够信号；
4. **可止损性**：时间、预算和机会成本是否可控；
5. **依赖关系**：是否是多个 P0/P1 的共同前置条件。

常见阶段侧重点仅作为筛选提示：

- 冷启动：先验证人群、卖点、内容或产品组合是否成立；
- 放量：先验证有效模型能否稳定复制，且供应与产能能否承受；
- 成熟期：先识别边际效率下降、结构性风险或可防守优势；
- 转型期：先验证新方向最关键、最便宜的假设，而不是同时铺开多条线。

最终只保留一个候选。并列时优先选能使最多后续决策发生变化、且两周内最可验证的一项。

## 7. 止损线

止损线至少选择两个维度：

- 时间：到哪一天停止；
- 预算：累计投入上限；
- 样本：达到多少有效样本仍未过线；
- 机会成本：因此延迟或放弃了什么；
- 替代方向：失败后切换到哪个假设。

所有数值必须来自会议、已有数据或明确标注的建议。没有基线时，先把“确定止损值”列为启动前置条件。
