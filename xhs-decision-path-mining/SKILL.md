# 小红书七段用户决策路径拆解

## 目标

把一批真实笔记拆成可追溯、可组合、可审核的内容元素库。按元素在用户决策中的功能归类，不按测评、清单、教程、故事等内容形式归类。

## 核心流程

1. 确认输入范围：品类、样本文件、分析目标、时间范围，以及是否含互动或转化数据。
2. 按 [references/batch-analysis.md](references/batch-analysis.md) 检查字段、去重、样本一致性和证据锚点；先报告有效样本量，不补齐或虚构缺失样本。
3. 先用一小批样本校准七段边界，再把标题和正文切成最小可解释片段进行批量编码；跨批合并同义表达时始终保留元素到原笔记的映射。
4. 按 [references/seven-stage-model.md](references/seven-stage-model.md) 判断每个元素的主阶段、心理问题、表达结构和使用边界。允许一个元素有次阶段，但只能有一个主阶段。
5. 用唯一笔记数计算 `support_count` 和 `coverage`，按证据强度排序。只有输入含可比的真实转化字段时，才分析转化关联。
6. 按 [references/output-spec.md](references/output-spec.md) 交付七个元素库、跨阶段组合方式、应用规则和待验证清单。
7. 交付前抽查每个高优先级元素：模板能否回溯到样本、心理解释是否标为推断、转化说法是否有相应数据。

## 开始前读取

- 任何分析都先完整读取 [references/batch-analysis.md](references/batch-analysis.md)。
- 开始归类前完整读取 [references/seven-stage-model.md](references/seven-stage-model.md)。
- 生成最终结果前完整读取 [references/output-spec.md](references/output-spec.md)。

## 输入与路由

- 接受 CSV、XLSX、JSON、Markdown、文档正文或用户粘贴的笔记集合。
- 最小内容字段是非空的 `body`；`title` 可以为空。标题为空但正文有内容时仍算有效样本，记录 `title_missing=true`，不得因此排除。优先要求 `note_id` 或稳定 URL；缺少稳定 ID 时，用文件名加行号生成只用于本次分析的 `source_anchor`。
- 标题、互动量、发布时间、作者、评论或转化字段均为可选信息；不得假设这些字段存在。
- 本 Skill 只分析用户已提供的数据。若用户还需要采集，先说明采集与分析是两个步骤，并使用当前环境中可用且获授权的小红书采集 Skill；不得因“分析 200–300 篇”而自行开始浏览。
- 品类混杂时先分层分析；除非用户明确要求比较，否则不得把不同品类合并成一个元素频次排名。

## 不可越过的证据边界

- 把样本文字、位置、频次和字段值标为【事实】；把心理功能、犹豫点和作用机制标为【推断】；把转化效果和因果关系标为【待验证】。
- 静态标题与正文只能判断表达位置，不能回答用户“第几秒”产生身份确认；没有视频时间码时改为标题、开头、正文前段等位置。
- “高频”“高互动关联”“高转化”是三种不同结论。没有曝光、点击、咨询、加购或成交等可比字段时，只输出高频元素和高潜候选。
- 不把“出现了信任线索”写成“用户已经相信”，不把行动提示写成“用户一定会行动”。
- 每个核心元素至少关联一个 `note_id` 或 `source_anchor`；找不到来源时删除该元素。
- 七段模型是本项目的分析视角，不是已被证明适用于所有消费者的普适心理学定律。
- 原文要求的元素数量是目标上限，不是凑数指标。样本只支持较少元素时，交付实际数量并说明缺口。
- 抽象复用模板，不大段复制原笔记；保留能证明判断的最短必要片段。

## 与用户协作

- 首次输入不完整时，先列出【已识别】和【需要确认】，每轮最多询问 3 个会改变分析结论的问题。
- 用户只给出少量样本时可以继续，但要把结果标为“小样本候选库”，不得包装成品类规律。
- 用户要求直接生成内容时，先确认是否要基于已完成的元素库组合；缺少已确认的品牌、产品或体验事实时，只生成带待补项的草稿。

## 完成标准

- 报告展示原始样本数、有效样本数、去重和排除情况。
- 七个阶段均有实际结果或明确的“证据不足”，没有静默缺段。
- 每个元素含复用结构、心理问题、证据计数、代表样本、结论级别和使用边界。
- 所有“最高转化”“最容易转化”类结论都有真实转化字段支撑；否则改为待验证候选。
- 最终产物可以直接用于内容组合、批量生成约束、审核清单和团队培训，但不会把候选规律冒充已验证因果。
