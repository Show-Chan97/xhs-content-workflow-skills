# 批量分析与证据保留

## 1. 建立分析清单

记录以下信息：

- `category`：本次品类；多个品类分别建组。
- `analysis_goal`：元素中台、内容模板、审核标准、培训材料或品类比较。
- `source_count`：收到的原始笔记数。
- `valid_count`：字段检查和去重后的有效笔记数。
- `time_range`：数据自带的发布时间范围；未知就写未知。
- `source_method`：关键词、账号、榜单、人工挑选或其他抽样方式；未知就写未知。
- `available_metrics`：互动、曝光、咨询、加购、成交等真实存在的字段。

不要因目标是 200–300 篇而复制样本、补写正文或把无效记录算入有效样本。

## 2. 生成稳定证据锚点

优先级如下：

1. 使用输入中的 `note_id`。
2. 没有 `note_id` 时使用规范化后的稳定 URL。
3. 两者都没有时生成 `<文件名>#<工作表或章节>#<行号>` 形式的 `source_anchor`。

所有候选元素在首次提取时就记录锚点和最短必要证据片段，不要在最终汇总时凭记忆补来源。

## 3. 检查与去重

- 标题为空、正文非空：保留为有效样本，记录 `title_missing=true`；这通常表示发布时未设置标题。
- 正文为空且没有可替代的正文转写或 OCR 内容：标记无效，并记录原因。只有标题不视为足够的正文样本。
- `note_id` 或稳定 URL 完全相同：只保留一条，记录重复数。
- 文本高度相似但 ID 不同：标记为疑似搬运或同模板变体，不自动删除。
- 品类、语言或时间范围明显混杂：先分层，不直接合并频次。
- 单一作者或账号占比过高：保留数据，但把来源集中度列为偏差。
- 指标单位或统计窗口不同：不得直接比较或加总。

在报告中公开排除规则、排除数量和仍存在的数据限制。

## 4. 分批提取

先选 20–30 篇覆盖不同来源和表达形态的样本校准分类边界，记录易混项和“无法判断”条件；冻结规则后再批量处理。大样本默认每批处理 30–50 篇；根据上下文容量缩小批次，不因追求固定批量而截断正文。

标题存在时独立编码；标题为空时跳过标题层，不把空标题当作证据或缺陷。正文按句子或完整语义片段切分，每个片段记录来源锚点和开头、正文前段、正文后段等位置；不要把整篇笔记当成一个不可分的标签单位。

每批完成两层输出：

1. 候选层：逐条识别七阶段元素，记录原始变体、来源锚点和所在位置。
2. 批次层：合并该批同义表达，但保留变体到来源的映射。

跨批汇总时：

- 合并语义和功能相同的表达，保留各自措辞变体。
- 相似措辞承担不同决策功能时不得强行合并。
- 测评、教程、清单、故事、图文、视频等内容类型不能成为七段元素的一级聚类名。
- 为元素分配稳定 ID：`ATT`、`REL`、`EMP`、`VAL`、`TRU`、`REA`、`ACT` 加三位序号。
- 一个元素指定一个主阶段；必要时另记 `secondary_stage`。

## 5. 计算证据强度

- `support_count`：支持该元素的唯一笔记数，不是出现次数。
- `coverage`：`support_count / valid_count`。
- `batch_repeat`：该元素出现于多少个分析批次。
- `author_count`：作者字段可用时，统计支持该元素的唯一作者数。
- `representative_sources`：至少列出 1 个，核心元素优先列出 3 个不同来源。

同一篇笔记重复出现同一结构，只增加表达变体，不重复增加 `support_count`。

按以下顺序排序：

1. 唯一笔记覆盖率；
2. 跨批重复性；
3. 来源多样性；
4. 在字段完整且可比时，才参考互动或转化表现。

“出现更频繁”不等于“造成更高转化”。若有转化数据，只能描述观察到的关联；要表达因果仍需实验或其他验证设计。

关键词、账号、榜单和平台排序会共同塑造样本。除非有能够代表总体的抽样设计，不得把这批笔记概括成全品类消费者的普遍规律。

## 6. 结论分级

- 【事实】：原文、位置、出现数量、字段值、覆盖率。
- 【推断】：元素对应的心理问题、信任类型、犹豫点或作用机制。
- 【待验证】：对点击、咨询、加购、成交的提升判断，以及任何因果结论。

置信度用于说明样本支持程度，不替代上述结论级别：

- 高：多个批次、多个来源重复出现，且功能解释一致。
- 中：重复出现但集中在少数来源、单一批次或同类模板。
- 低：少量样本、解释歧义明显或依赖缺失字段。

## 7. 质量复核

交付前检查：

- 随机抽查每个阶段至少 2 个元素，确认来源可定位。
- 检查核心元素的 `support_count` 是否按唯一笔记计数。
- 检查模板是否保留变量位，而不是简单改写某篇原文。
- 搜索“最高转化”“最有效”“一定”“必然”等词，逐条核对数据依据。
- 检查所有证据不足的阶段是否明确写出缺口和下一步验证方式。
- 样本量允许时保留一部分笔记不参与元素命名，用它检查元素库覆盖率、未分类比例和证据可追溯性。
