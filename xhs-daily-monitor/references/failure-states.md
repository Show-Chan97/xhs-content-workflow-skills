# 状态与失败降级

## 状态

- `INTAKE`：正在采集信息。
- `AWAITING_CONFIRMATION`：确认单已生成，尚未获准执行。
- `READY`：已确认，可开始执行。
- `READ_ONLY_READY`：可采集，但飞书目标或授权不完整。
- `BLOCKED`：关键条件缺失。
- `PARTIAL_COMPLETE`：部分采集或写入完成，限制已披露。
- `COMPLETE`：采集、追加和复核均完成。

## 处理表

| 情况 | 行为 |
|---|---|
| 浏览器不可用 | `BLOCKED`，不采集 |
| Chrome 未登录 | 请用户自行登录，不索取凭据 |
| 登录墙、验证码、风控 | 立即停止，保存进度并报告位置 |
| 单篇不可访问 | 跳过并记录，不反复刷新 |
| 互动数据不完整 | 标记或排除，不估算 |
| 达标样本不足 | 只走已授权回补层，仍不足则按实际数量交付 |
| 零结果 | 按配置决定是否追加零结果日报，并写明口径 |
| 重复过多 | 报告重复数，不计入目标 |
| 飞书无权限 | 保留待写日报，进入 `READ_ONLY_READY` |
| 当天章节存在 | 执行已确认的同日策略 |
| XML 或写入失败 | 修正后最多安全重试一次，仍失败则保留待写内容 |
| `partial_success` | 检查警告和新增块，复核后如实报告 |
| 网络中断 | 保存已采 `note_id` 和关键词进度，从未完成处续跑 |

任何中断都要报告已完成数、中断原因、保存位置和继续条件，不得宣称未完成部分已交付。
