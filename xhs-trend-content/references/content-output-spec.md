# 内容草稿规范

## 生成原则

1. 只使用用户确认的品牌名、产品名、目标人群、卖点依据和真实资料。
2. 各篇采用不同内容角度；角度不足时先请用户补充或允许系统推荐。
3. 竞品对比只写公开可核实信息。无公开配方、比例或测试资料时，只能描述公开口碑、颗粒、便利性和评论反馈。
4. 用户要求第一人称但未提供真实体验时，将状态标记为 `DRAFT_ONLY`，正文前列出【需用户补充/替换】。
5. 区分【事实依据】【基于样本的推断】【待验证】，不得把趋势观察包装成产品事实。

## 每篇输出

```text
状态：READY / DRAFT_ONLY
内容角度：
标题候选（5 个）：
封面压字（3 条）：
正文：
置顶评论（3 条）：
图片或视频分镜（5–6 个）：
使用到的趋势词或句式：
【事实依据】
【基于样本的推断】
【需用户补充/替换】
```

标题、正文和分镜必须彼此对应。不要只替换产品名批量复制同一结构。
