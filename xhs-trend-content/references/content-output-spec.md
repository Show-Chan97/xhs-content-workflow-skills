# 迪安版完整交付与内容草稿规范

## 总原则

1. 只使用用户确认的品牌名、产品名、目标人群、卖点依据和真实资料。
2. 完整交付默认按下列七段结构输出，不得只交付草稿。某段无数据时写“暂无”“未创建”或“待核验”，不得静默省略。
3. 旧版文件只提供版式。狗粮词、品牌 A/B、每日 9 点、300 互动门槛、第一人称体验和具体卖点都必须换成当次确认结果。
4. 区分【事实依据】【基于样本的推断】【待验证】，不得把趋势观察包装成产品事实。
5. 飞书文档可在页首使用一个概览 `callout`；普通 Markdown 或聊天输出改用引用段落，不强制输出飞书专用标签。
6. 用户明确要求简版时可压缩说明文字，但仍须保留样本来源、事实边界、草稿状态和发布前待补信息。

除非用户明确指定其他标题，一级栏目名必须使用以下字面格式，不用“今日样本”“后续任务说明”等同义标题替换：

1. `本次执行状态` 或 `自动任务状态`，二选一；
2. `今日抓取样本`；
3. `本轮爆款词与句式`；
4. `产品信息转译`；
5. 默认 `每日三篇笔记视角`；用户指定其他数量时只替换篇数；
6. `下次自动任务输出格式`；
7. `发布前需要补充的信息`。

## 页首概览

用一句话概括：时间范围、品类、实际样本量、趋势内容、草稿数量、立即或定时执行状态。不要把计划数量写成实际完成数量。

## 1. 本次执行状态 / 自动任务状态

立即执行使用“本次执行状态”；只有已创建并验证定时任务时才使用“自动任务状态”。用“项目 / 内容”两列表格，按顺序输出：

1. 任务名；
2. 任务 ID：立即执行或未创建时写“未创建”，不得编造；
3. 执行时间与时区；
4. 执行方式与浏览器执行器；
5. 抓取范围；
6. 筛选标准；
7. 实际输出；
8. 安全边界。

## 2. 今日抓取样本

表格前固定说明：互动量来自采集时页面可见数据，仅作选题和表达参考，不等于独立用户数、真实商业转化或产品效果。

样本表固定使用以下列顺序：

| 标题 | 发布时间 | 可见互动 | 关键词来源 | 内容判断 | 可借鉴点 |
|---|---|---|---|---|---|

- 标题链接到原笔记，并在同一格附 `note_id`；没有 `note_id` 时标记临时去重键。
- 可见互动写成“赞 X / 藏 X / 评 X / 可见小计 X”。不可见项写“不可见”，禁止写 0 或猜测；部分可见时明确标注。
- 内容判断描述内容类型、关联强弱和可见推广迹象，不把“疑似推广”写成确定性指控。
- 可借鉴点只提炼场景、叙事、标题结构、镜头或评论问题，不复制无法证明的功效结论。
- 表后写实际达标样本数、计划上限、排除原因、促销或活动样本占比，以及其他会影响解释的偏差。样本不足时按实际数量交付。

## 3. 本轮爆款词与句式

“爆款”仅表示本批高互动样本中的内容分析标签，不代表全网结论。按当次样本动态输出，不硬编码狗粮分类：

- 将高频词分成 2–4 个有意义的类别，如生活场景、购买复购、痛点需求、产品话题；
- 分开列出样本中可见的原词与“基于样本改写的标题句式”，不能把改写句式冒充原帖原话；
- 归纳标题结构、开头方式和常见内容形式；
- 单列“评论区高频问题”，只写本批可见评论中的问题；
- 单列“推广 / 活动信号”，说明哪些互动可能受直播、抽奖、试吃、赠品或竞猜影响；
- 个案写“单篇样本观察”，多篇重复出现后才可写“本批样本中较常见”。

## 4. 产品信息转译

先显示经用户确认的产品全名。名称疑似错误时使用醒目提示并暂停成稿，不自行更名。

产品转译表固定为：

| 原始卖点 | 依据状态 | 建议表达 | 避免表达 |
|---|---|---|---|

- `依据状态` 写明资料来源，如品牌包装、配料表、商品详情页、检测材料、真实观察或【待核验】。
- 没有依据时，`建议表达` 必须写“【待核验，不进入正文】”，不能先把卖点降调后继续使用。
- 有依据时也只做合规转译，不加入来源没有支持的比较、效果、时长或适用人群。
- `避免表达` 同时约束标题、封面字、正文、标签、置顶评论和分镜字幕。

## 5. 每日三篇笔记视角

默认输出 3 个不同视角。各篇必须真正改变目标人群、问题场景或叙事路线，不能只替换产品名。

每篇按以下顺序输出：

```text
视角一 / 二 / 三：视角名
状态：READY / DRAFT_ONLY
目标人群：
内容角度：
【需用户补充/替换】（DRAFT_ONLY 时必须放在标题和正文之前）
标题备选（5 个）：
封面压字（3 条）：
正文草稿（默认 250–450 字）：
话题标签（默认 5–8 个）：
置顶评论（3 条）：
分镜建议（5–6 个）：
使用到的趋势词或句式：
【事实依据】
【基于样本的推断】
```

正文可参考“真实场景或问题 → 选择过程 → 已核验产品信息 → 条件化人群建议 → 生活感收尾”的节奏。未提供真实体验时，不得写“我家”“吃了几天”“实际对比下来”等已发生叙事；改写为观察计划、待补字段或第三人称说明。

竞品对比只在用户确认允许后使用。无公开配方、比例或测试资料时，只能比较本批公开笔记的表达方式、颗粒展示、渠道便利性和评论疑问；不强制每篇加入品牌 A / B，也不贬低竞品。

标题、封面、正文、标签和分镜必须对应同一角度。结果型标题必须有真实记录支持，否则改成问题式、记录式或待验证表达。

## 6. 下次自动任务输出格式

- 已创建定时任务：写明任务名、任务 ID、执行时间、频率和时区，再列出下次仍会输出的七项内容。
- 立即执行或未创建任务：明确写“本次未创建自动任务”，不得声称“明天会自动输出”。如用户需要定时任务，重新进入确认流程。
- 本节只说明已确认的后续机制，不承担创建任务的动作。

下次交付清单保持为：达标样本列表、爆款词与句式、评论问题、推广 / 活动信号、产品信息转译、多视角草稿、发布前待补信息。

## 7. 发布前需要补充的信息

将所有草稿中的占位字段去重后汇总成一份可勾选清单。至少检查：

- 品牌与产品名称；
- 卖点对应的包装、配料、详情页或其他事实材料；
- 真实使用者身份、使用周期、使用方式和可观察记录；
- 竞品名称与允许比较的范围；
- 图片、颗粒、使用过程等真实素材；
- 行业合规与用户禁用表达。

宠物食品任务可按需补充犬种、月龄、体重、是否绝育、原粮、换粮比例、喂养天数、采食、剩粮、便便、眼角与异常记录；这些是品类字段，不得硬编码到其他品类。
