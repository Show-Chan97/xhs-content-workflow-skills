# 输出契约

## 目录

1. 报告开头
2. 逐条五步诊断

4. 禁用写法

## 报告开头

先写诊断范围和数据质量：

```text
诊断窗口：{开始日期}—{结束日期}
数据粒度：{一条笔记×一个窗口快照}
本次阈值：CTR ≥ {x}%｜7日ROI ≥ {x}｜止损线累计消费 ≥ {x}元且连续 ≥ {x}天无成交
数据质量：{完整 / 有缺失 / 有冲突}
```

当天总消费 `<100` 元或有效投流笔记 `<5` 条时，加：

```text
⚠️ 今日数据量偏小：总消费 {x} 元、有效投流笔记 {n} 条。以下结论按当前样本成立，需在 {明确天数/样本量} 后复核。
```

## 逐条五步诊断

按 `🟢 → 🟡 → 🔵 → 🔴 → 自然流/未分类` 排序。

目标人群+卖点为空时，第一行先写：

```text
⚠️ 缺少人群定位，补全后才有完整的人群诊断意义。
```

### 1. 象限与定调

```text
{象限} | 笔记「{标题}」 | {时间窗口}
【事实】消费 {x} 元｜CTR {x}%｜7日ROI {x}｜支付 {x} 元
【派生】按 CTR {x}%、ROI {x} 的本次阈值，归入{象限}。
```

自然流或关键字段缺失时写“未进入投流四象限”，不要补造 ROI。

### 2. 漏斗断点

```text
断裂点：{层级 / 暂未定位}
【事实】{相关分子、分母和比率}
【推断】{最可能的 1–2 个方向}
【待验证】{要核查的素材或字段}
```

### 3. 人群切片匹配度

```text
人群切片匹配度：✅ 匹配 / ⚠️ 部分匹配 / ❌ 不匹配 / 待验证
- 标注人群：{人群}-{卖点}
- 数据验证：{本条数字 + 同人群对照}
- 判断：{结论或待验证说明}
```

### 4. 内容框架评价

```text
内容框架评价：
- 封面：{实际识别 / 未提供素材} → {判断}
- 标题：{实际类型} → {承诺是否兑现}
- 正文：行动按钮CTR {x}% → {判断}
- 评论区：{已读取 / 未读取} → {判断或待验证}
```

没有实际素材时保留“未提供素材”，不得从 CTR 猜具体类型。

### 5. 唯一首要行动

```text
→ {一个行动}：{数字与阈值差异}。{具体操作}；{明确复核条件}。
```

## 全局策略洞察

逐条诊断之后固定输出四组内容。

### 黄金组合

```text
🔥 黄金组合：{人群} × {卖点} × {内容框架}
- 代表笔记：{1–3 条}
- 样本数 {n}｜平均CTR {x}%｜平均7日ROI {x}
- 建议：{拆解并生成多少条变体，以及复核条件}
```

没有足够重复样本时写“暂未形成可验证的黄金组合”，并说明所需样本。

### 待验证信号

优先列：展现 `<500` 但 CTR 达标、CTR 未达标但有成交、新人群出现正 ROI 的笔记。每条都给测试时长、预算或样本上限。

### 应停止方向

只在证据成立时列出：同一人群连续至少 5 条无成交、同一框架多条 CTR 均 `<3%`、或连续 7 天 ROI `<0.3`。不足条件时写“当前无达到停止证据的方向”。

### 团队协作

列 1–3 条可当天处理的问题，例如补全人群标注、校准达人/素人预算、排查投放无数据。必须附数量和影响金额。

## 禁用写法

- “表现不错”“数据一般”“可以继续观察”。
- “点击率低，所以封面一定不好”。
- “正文 100% 有问题”“评论区把用户劝退了”。
- 没有数字、阈值、时间窗口或验证条件的建议。
- 为满足模板而虚构黄金组合、成交、素材观察或用户行为。
