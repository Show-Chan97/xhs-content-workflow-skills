# 单一行动政策

## 原则

每条笔记只输出一个首要行动。可以补充“验证条件”，但不能同时要求加预算、停投和继续观察。

动作优先级：

1. 数据冲突或投放设置异常
2. 止损红线
3. 放大高效笔记
4. 修复明确漏斗断点
5. 更换人群测试
6. 小样本观察

## 动作表

| 首要行动 | 触发条件 | 具体做法 | 证据要求 |
|---|---|---|---|
| 🧪 校验数据 | ROI、支付、百分比或时间窗互相冲突 | 回到数据源核对口径，未校验前不做投放决策 | 必须指出冲突字段 |
| 🚧 排查投放设置 | 展现 `<100` 且消费 `>10` 元 | 查审核、出价、人群范围和计划状态 | 不先归咎内容 |
| ✂️ 停投止损 | 累计消费 `≥150` 元、连续 `≥3` 天无成交 | 建议关停并保留诊断记录 | 三个条件必须同时有事实证据 |
| 📈 加预算放大 | 7 日 ROI 达到本次门槛、至少 3 天稳定且明确未见衰减 | 每日递增 `20%–30%`，记录 ROI 衰减 | 缺少稳定或衰减证据时先受控验证；不自动改预算 |
| 🔧 改封面标题 | CTR 未达门槛但已有转化 | 基于高点击同组样本做 3 版，各用受控小预算测试 | 不能只凭 CTR 猜封面类型 |
| ✏️ 改正文 CTA | CTR 达标但行动按钮 CTR `<1%` | 保留封面标题，重写正文后半段和 CTA | 先确认行动 CTR 分母 |
| 🔄 换人群标签 | CTR 达标，且实际核查确认正文与商品关联无明显问题但无成交 | 保留内容，新计划换人群包测 3 天 | 未完成内容核查时先补证据，不直接换人群 |
| 👀 观察 3 天 | 新笔记或新人群、展现 `<500` 且已有零星成交 | 明确再测 3 天及目标展现/消费 | 禁止只写“再观察” |
| 📋 模板化 | 7 日 ROI `>2` 且稳定至少 7 天 | 拆标题、封面、正文和人群为变体模板 | 通常放进全局策略，不与加预算冲突 |

## 冲突处理

- 命中数据冲突时，`校验数据` 覆盖所有业务动作。
- 命中投放设置异常时，先修投放能力，不先改内容。
- 命中止损红线时，`停投止损` 覆盖改稿、换人群和观察。
- 绿区只有在稳定天数和“未见 ROI 衰减”都得到明确验证时才放大；否则先做有上限的受控验证。“模板化”进入全局策略。
- 蓝区优先改封面标题；黄区若行动按钮 CTR 低则改正文 CTA，否则先核查内容与商品，核查通过后再考虑换人群。
- 红区未达到止损证据时，不把“放弃区”自动等同于强制停投；给出有上限的补测或暂停诊断条件。

## 行动句式

使用以下结构：

```text
→ {行动}：{当前数字}，相对本次阈值{差异}。{具体操作}；在{时间/预算/样本上限}后按{成功或失败指标}复核。
```

示例：

```text
→ 🔧 改封面标题：近 3 天 CTR 2.3%，低于本次 5% 阈值 2.7 个百分点；保留正文，制作 3 版封面标题，各投 50 元，CTR 达到 5% 后再评估放量。
```

不得把建议直接执行到投放账户，除非用户另行明确授权并确认具体计划、预算和风险。
